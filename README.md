# ⚔️ سیستم سولو لولینگ (Solo Leveling System)

اپ کامل سولو لولینگ برای اندروید — **ساختهٔ ارشام**

یک فایل HTML → یک فایل APK. تم کاملاً مشکی، فونت فارسی وزیرمتن، راست‌چین، پس‌زمینهٔ زنده، بدون متن انگلیسی در رابط کاربری.

## 📦 خروجی APK (آمادهٔ نصب)

**فایل `solo-leveling-system.apk` در ریشهٔ مخزن** — دانلود کن و روی اندروید نصب کن (اجازهٔ نصب از منابع ناشناس را بده).

- نام برنامه در لانچر: **ارشام** — داخل برنامه: **سیستم سولو لولینگ**
- سازگار با اندروید ۴.۰ به بالا (minSdk 15) — روی همهٔ گوشی‌ها نصب می‌شود
- امضای v1 معتبر + آیکون اختصاصی + بارگذاری کامل آفلاین

### بازسازی APK
```bash
npm run build                    # ساخت www/index.html (همه‌چیز داخل یک فایل)
python3 scripts/make-apk.py      # پچ قالب + امضا + اعتبارسنجی خودکار
# پیش‌نیاز پایتون: pip install pillow
# اعتبارسنجی: pip install aapt2 androguard
```

## ✨ قابلیت‌ها (همه واقعی کار می‌کنند)

### سیستم لِوِل (گرایند واقعی)
- لِوِل‌آپ فقط با کلیک واقعی: سطح ۶ ≈ ۲۰۰۰ کلیک، سخت‌تر شدن نمایی تا **سطح ۱۰۰۰ (پادشاه سایه‌ها)**
- با هر لِوِل‌آپ: **۳ انتخاب جایزه در روز** — جوایز هر روز متفاوت و واقعی
- هیچ‌چیز از اول فعال نیست: مهارت‌ها باید گرایند شوند تا باز شوند

### ماموریت‌ها (۱۰۰۰+ ترکیب)
- **هر ۲ ساعت یک ماموریت جدید** + اعلان داخل برنامه
- **ماموریت اجباری**: اگر انجام نشود → **مجازات واقعی** (کم‌شدن طلا، دیباف قدرت ۲۴ ساعته، فلش قرمز، آژیر)
- ماموریت‌های روزانهٔ اجباری + **مسیر یک‌سالهٔ ۳۶۵ روزه** با داستان — غیبت = مجازات و شکستن زنجیره

### دروازه‌ها / دانجن‌ها
- **۱۰٬۰۰۰ دانجن واقعی** — از رتبهٔ E تا دروازهٔ نهایی پادشاه سایه‌ها (سطح ۱۰۰۰)
- هر دانجن: داستان فارسی، موج‌های دشمن، باس آخر، جایزهٔ واقعی متناسب با سختی
- تب دروازه **از همان اول باز است**

### باس‌ها (۱۰۰۰ تا)
- نبرد واقعی: **باس واقعاً به تو آسیب می‌زند**، حالت خشم، مهارت‌های مخصوص، جاخالی، کریت، سپر، سم، یخ‌زدگی...
- بعد از هر باس: **«برخاستن!» (Arise)** — تبدیل روح دشمن به سایهٔ خودت (با سنگ سایه شانس را بالا ببر)

### مهارت‌ها (۱۰۰۰ تا) + سایه‌ها
- ۳۰ نوع افکت، شرط گرایند برای هر مهارت، **تا ۴ مهارت هم‌زمان فعال** از تب کیف
- تا ۳ سایهٔ همراه — قدرت و جان واقعی اضافه می‌کنند و در نبرد کنارت می‌جنگند

### فروشگاه پیشرفته (۱۰۵ آیتم)
- ۷ دسته: سلاح، زره، معجون، طومار، سنگ سایه، عنوان، ویژه + **۳ تخفیف روزانه** + خرید/فروش/تجهیز

### رقابت آنلاین (حریف واقعی، بدون ربات)
- چالش مستقیم با بازیکنان آنلاین + صف یافتن حریف
- **شوتر دوبعدی واقعی هم‌زمان** یا مسابقهٔ کلیکی ۳۰ ثانیه‌ای — برد/باخت واقعی با جایزه

### چت آنلاین
- اتاق‌ها + **ساخت گروه** + پیام خصوصی + **پیام صوتی** + **صحبت زندهٔ واکی‌تاکی**
- پیام‌ها در دیتابیس ذخیره می‌شوند — با بستن برنامه از بین نمی‌روند

### لیدربرد جهانی
- رتبه‌بندی واقعی همهٔ کاربران بر اساس قدرت/سطح/تجربه/بردها/امتیاز + رنک خودت
- نام کاربری **برای همیشه** ثابت می‌ماند

### ابر و ذخیره‌سازی (Supabase)
- ثبت‌نام/ورود با **نام کاربری + رمز عبور** (هش امن SHA-256 در سرور)
- **همه‌چیز** در ابر ذخیره می‌شود: خریدها، مهارت‌ها، سایه‌ها، ماموریت‌ها، مجازات‌ها...
- ورود خودکار + ذخیرهٔ محلی: با بستن برنامه یا آپدیت، **هیچ‌چیز گم نمی‌شود**

## ☁️ راه‌اندازی دیتابیس (یک بار، ۲ دقیقه)

اپ خودش راهنما دارد (تنظیمات → نصب دیتابیس). خلاصه:
1. وارد [Supabase Dashboard](https://supabase.com/dashboard/project/baooyxmxzkzwimitjfjk/sql/new) شو
2. محتوای فایل `sql/schema.sql` را Paste کن و **Run** بزن
3. تمام! از داخل اپ «بررسی دوباره» را بزن

بدون این مرحله بازی آفلاین کار می‌کند ولی حساب/لیدربرد/چت/رقابت ابری فعال نمی‌شوند.

## 🛠 ساختار

```
src/index.html        → پوستهٔ برنامه (فارسی RTL)
src/styles.css        → تم تاریک کامل
src/js/*.js           → موتور، داده‌ها، ابر، نبرد، UI
sql/schema.sql        → دیتابیس Supabase (RLS امن + ری‌تایم + صدا)
build.mjs             → ساخت یک فایل واحد www/index.html
scripts/make-apk.py   → ساخت APK (پچ قالب + امضا + اعتبارسنجی)
android/              → پروژهٔ Capacitor (برای بیلد با Android Studio)
```

> قالب WebView پایه از پروژهٔ متن‌باز `successtar/web-to-app` گرفته شده و با ابزارهای آزاد (aapt2/openssl) سفارشی‌سازی شده است.
