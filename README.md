# ⚔️ سیستم سولو لولینگ (Solo Leveling System)

اپ کامل سولو لولینگ برای اندروید — **ساختهٔ ارشام**

یک فایل HTML → یک فایل APK. تم کاملاً مشکی، فونت فارسی وزیرمتن، راست‌چین، پس‌زمینهٔ زنده، بدون هیچ متن انگلیسی در رابط کاربری.

## ✨ قابلیت‌ها (همه واقعی کار می‌کنند)

### سیستم لِوِل (گرایند واقعی)
- لِوِل‌آپ فقط با کلیک واقعی: سطح ۶ ≈ ۲۰۰۰ کلیک، سخت‌تر شدن نمایی تا **سطح ۱۰۰۰ (پادشاه سایه‌ها)**
- با هر لِوِل‌آپ: **۳ انتخاب جایزه در روز** — جوایز هر روز متفاوت و واقعی (طلا، جواهر، آیتم، XP...)
- هیچ‌چیز از اول فعال نیست: مهارت‌ها باید گرایند شوند تا باز شوند

### ماموریت‌ها (۱۰۰۰+ ترکیب)
- **هر ۲ ساعت یک ماموریت جدید** + نوتیفیکیشن
- **ماموریت اجباری**: اگر انجام نشود → **مجازات واقعی** (کم‌شدن طلا، دیباف قدرت ۲۴ ساعته، فلش قرمز، آژیر)
- ماموریت‌های روزانهٔ اجباری (تا آخر شب مهلت داری)
- **مسیر یک‌سالهٔ ۳۶۵ روزه** با داستان — هر روز کار جدید + جایزه؛ غیبت = مجازات و شکستن زنجیره

### دروازه‌ها / دانجن‌ها
- **۱۰٬۰۰۰ دانجن واقعی** — از رتبهٔ E تا دروازهٔ نهایی پادشاه سایه‌ها (سطح ۱۰۰۰)
- هر دانجن: داستان فارسی، موج‌های دشمن، باس آخر، جایزهٔ واقعی (طلا + XP + شانس سایه) متناسب با سختی
- تب دروازه **از همان اول باز است** (بدون قفل)

### باس‌ها (۱۰۰۰ تا)
- سیستم نبرد واقعی: **باس واقعاً به تو آسیب می‌زند**، حالت خشم زیر ۴۰٪ جان، مهارت‌های مخصوص هر باس، جاخالی، کریت، سپر، سم، یخ‌زدگی...
- بعد از هر باس: **«برخاستن!» (Arise)** — شانس تبدیل روح دشمن به سایهٔ خودت؛ باید با سنگ سایه شانس را بالا ببری (یا چیزی بشکنی!)

### مهارت‌ها (۱۰۰۰ تا)
- ۳۰ نوع افکت (شفا، خشم، سم، یخ، شهاب، احضار سایه، خون‌آشام، بازتاب، اعدام...)
- هر مهارت شرط گرایند دارد (کلیک/باس/دانجن/رقابت/استخراج) + هزینهٔ طلا
- **تا ۴ مهارت هم‌زمان فعال** — از تب کیف فعال/غیرفعال کن
- سایه‌های استخراج‌شده: تا ۳ سایه همراه → قدرت و جان واقعی اضافه می‌کنند و در نبرد کنارت می‌جنگند

### فروشگاه پیشرفته (۱۰۵ آیتم)
- ۷ دسته: سلاح، زره، معجون، طومار، سنگ سایه، عنوان، ویژه
- **۳ تخفیف روزانه**، خرید با طلا/جواهر، فروش، تجهیز سلاح/زره/عنوان
- هر خرید واقعاً به کیف می‌رود و در ابر ذخیره می‌شود

### رقابت آنلاین (حریف واقعی، بدون ربات)
- چالش مستقیم با بازیکنان آنلاین + صف یافتن حریف
- **شوتر دوبعدی واقعی هم‌زمان** (جوینت‌استیک + شلیک + پاورآپ) یا مسابقهٔ کلیکی ۳۰ ثانیه‌ای
- برد/باخت واقعی: طلا، XP، امتیاز رنک — همه در ابر ثبت می‌شود

### چت آنلاین
- اتاق‌های عمومی/رقابت/دروازه‌ها + **ساخت گروه** + پیام خصوصی
- **پیام صوتی** (ضبط → آپلود ابری) + **صحبت زندهٔ واکی‌تاکی**
- پیام‌ها در دیتابیس ذخیره می‌شوند — با بستن برنامه **از بین نمی‌روند**

### لیدربرد جهانی
- رتبه‌بندی واقعی همهٔ کاربران بر اساس **قدرت / سطح / تجربه / بردها / امتیاز** + رنک خودت
- نام کاربری **برای همیشه** ثابت می‌ماند

### ابر و ذخیره‌سازی (Supabase)
- ثبت‌نام/ورود با **نام کاربری + رمز عبور** (هش امن SHA-256 در سرور)
- **همه‌چیز** در ابر ذخیره می‌شود: خریدها، مهارت‌ها، سایه‌ها، دانجن‌ها، باس‌ها، ماموریت‌ها، مجازات‌ها...
- ورود خودکار + ذخیرهٔ محلی: حتی اگر برنامه را ببندی یا اینترنت قطع شود، **هیچ‌چیز گم نمی‌شود**
- اگر برنامه آپدیت شود، حساب و همهٔ داده‌ها سر جایشان هستند

## 📱 خروجی APK

APK آمادهٔ نصب: از بخش **Actions** مخزن (آرتیفکت `solo-leveling-system-apk`) — فایل `solo-leveling-system.apk`

برای بیلد دستی:
```bash
npm ci
npm run build          # ساخت www/index.html (همه‌چیز داخل یک فایل)
npx cap sync android
cd android && gradle assembleDebug
```

## ☁️ راه‌اندازی دیتابیس (یک بار)

اپ خودش راهنما دارد (تنظیمات → نصب دیتابیس): فایل `sql/schema.sql` را در
[SQL Editor](https://supabase.com/dashboard/project/baooyxmxzkzwimitjfjk/sql/new) پروژه‌ات Paste و Run کن.
اگر secret به نام `SL_DB_PASSWORD` در مخزن ست شود، GitHub Actions خودش این کار را می‌کند و تست یکپارچه‌سازی هم می‌گیرد.

## 🧪 تست‌ها

```bash
npm test        # ۱۹ تست موتور بازی (سختی، اقتصاد، مجازات، ماموریت، سایه...)
npm run test:ui # ۱۵ تست رابط کاربری در DOM شبیه‌سازی‌شده
node ci/test-integration.mjs  # تست ابر واقعی (در CI)
```

## 🛠 ساختار

```
src/index.html        → پوستهٔ برنامه
src/styles.css        → تم تاریک کامل (RTL)
src/js/*.js           → موتور، داده‌ها، ابر، نبرد، UI
sql/schema.sql        → دیتابیس Supabase (RLS امن + ری‌تایم + صدا)
build.mjs             → ساخت یک فایل واحد www/index.html
android/              → پروژهٔ Capacitor اندروید
```
